## 1. BigRock Multi Domain Hosting Plan Limitations & Compatibility Checklist
*(మీ నిర్దిష్ట BigRock Multi Domain Hosting ప్లాన్ పరిమితులు మరియు పరిష్కారాలు)*

Before deploying on BigRock Multi Domain Linux Hosting (cPanel), verify these plan-specific parameters in cPanel:

1. **PHP Version (`MultiPHP Manager`)**:
   - BigRock Multi Domain plans sometimes default new addon domains to PHP 7.4 or 8.0.
   - **Action:** Open **cPanel → Software → MultiPHP Manager**, select `netibhaaratham.com`, and set the PHP version to **PHP 8.2** or **PHP 8.3**.
2. **Required PHP Extensions (`Select PHP Version` / `MultiPHP INI Editor`)**:
   - Verify that `pdo`, `pdo_mysql`, `mbstring` (essential for Telugu Unicode), `openssl` (for AES-256 identity document encryption), `fileinfo` (MIME validation), `gd` (image compression/thumbnails), and `zip` are enabled.
3. **Upload Size & Post Limits (`MultiPHP INI Editor`)**:
   - Reporters upload high-resolution mobile gallery photos and PDF identity documents.
   - Set `upload_max_filesize = 16M`, `post_max_size = 24M`, `memory_limit = 256M`, and `max_execution_time = 60`.
4. **Inode & Storage Governance (BigRock Shared Hosting Limit)**:
   - BigRock Multi Domain Linux plans enforce an inode soft/hard limit (typically 150,000–250,000 files).
   - NETI BHARATHAM automatically compresses uploaded news images and restricts private advertisements to a **maximum of 2 images per submission** to conserve disk space and inodes.
5. **Private Directory Placement Outside `public_html`**:
   - For the primary domain on BigRock cPanel, `public_html/` is `/home/<cpanel_user>/public_html` and `private/` is placed at `/home/<cpanel_user>/private` (completely unreachable via HTTP).
   - If `netibhaaratham.com` is configured as an **Addon Domain** inside `/home/<cpanel_user>/netibhaaratham.com`, place `private/` at `/home/<cpanel_user>/private_netibhaaratham/` AND keep `.htaccess` with `Require all denied` inside `private/identity_documents/` and `private/backups/` as dual-layer defense.

## 3. Step-by-Step Installation Process on BigRock cPanel

1. **Create MySQL Database in cPanel**:
   - Open **cPanel → Databases → MySQL® Database Wizard**.
   - Create database: `<cpaneluser>_netibharatham`.
2. **Create Database User & Assign Permissions**:
   - Create user: `<cpaneluser>_nbadmin` with a strong password.
   - Grant **ALL PRIVILEGES** on `<cpaneluser>_netibharatham`.
3. **Upload Production Files**:
   - Upload the contents of `private/` to `/home/<cpanel_user>/private/`.
   - Upload the contents of `public_html/` (including the production build `dist/` files) to `/home/<cpanel_user>/public_html/`.
4. **Set Correct Folder Permissions**:
   - Directories inside `public_html/`: `0755` (`uploads/`: `0750`).
   - Files inside `public_html/`: `0644`.
   - `private/config/config.php`: `0600`.
5. **Enable SSL (HTTPS)**:
   - Open **cPanel → Security → SSL/TLS Status** and run **AutoSSL** for `netibhaaratham.com` and `www.netibhaaratham.com`.
6. **Run Secure First-Run Installation Wizard**:
   - Visit `https://netibhaaratham.com/install.php`.
   - Verify all 7 BigRock compatibility checks show **PASSED**.
   - Enter your cPanel MySQL credentials and choose your initial **Super Admin** password (no hardcoded passwords exist in code or SQL).
7. **Lock & Remove Installer**:
   - `install.php` creates `private/config/installed.lock` automatically.
   - Delete `public_html/install.php` via cPanel File Manager.

## 4. Backup and Recovery Instructions

1. **Automated Admin Dashboard Backups**:
   - Log in as **Super Admin → Security & Backups** to generate and download a complete SQL & configuration snapshot at any time.
   - Backups are stored in `private/backups/` (protected by `.htaccess` `Require all denied`) and streamed only to authenticated Super Admins.
2. **cPanel Full Recovery Procedure**:
   - To restore the database: Open **cPanel → phpMyAdmin**, select `<cpaneluser>_netibharatham`, and import your `.sql` backup file.
   - To restore uploaded media: Extract the `uploads_backup.zip` archive into `public_html/uploads/` and `private/identity_documents/`.
